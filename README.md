# FixIT
Proyecto académico para la gestión de la configuración el software FixIT (Mesa de Soporte Técnico). Este espacio implementa el control de versiones, trazabilidad, elementos de configuración (CI), Líneas base (LB-1.0, LB-1.1, LB-1.2) y la gestión formal de solicitudes de cambio (CR-001, CR-002, CR-003) en el marco de la asignatura Inge de Software 2
